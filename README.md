# Banking Cloud Platform

AWS DevOps project: Terraform, Jenkins CI/CD, Docker and Kubernetes (EKS).

## Folders

| Folder | What it holds |
|---|---|
| `terraform/` | AWS infrastructure (VPC module, dev/staging/prod) |
| `jenkins/` | Jenkinsfile (CI pipeline) |
| `iam/` | IAM policy files for the tools server role |
| `scripts/` | Bash scripts: setup, health check, deploy |
| `services/` | Banking microservices (coming next) |
| `k8s/` | Kubernetes files (coming later) |
| `monitoring/` | Prometheus and Grafana (coming later) |
| `docs/` | Notes and incident write-ups |
